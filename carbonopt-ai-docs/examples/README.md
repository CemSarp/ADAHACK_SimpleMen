# Contract Example Payloads

These JSON files are delivered examples, ready to copy into C0 fixture tests. They are synthetic and use mock provenance; none claims a trained forecast, completed optimization search, calibrated risk model or real external benchmark.

| File | Contents |
|---|---|
| [baseline_12m.json](baseline_12m.json) | Complete flat synthetic baseline, 12 monthly rows |
| [action_config.json](action_config.json) | Nonzero six-action example |
| [action_assumptions.json](action_assumptions.json) | Complete illustrative deterministic assumption object |
| [constraints.json](constraints.json) | Horizon budget, profit floor and reduction target |
| [simulation_noop.json](simulation_noop.json) | No-op monthly rows and reconciled metrics |
| [simulation_nonzero.json](simulation_nonzero.json) | Hand-equation scenario including interactions/costs |
| [optimization_ok.json](optimization_ok.json) | One validated feasible candidate/frontier; illustrative result shape |
| [optimization_infeasible.json](optimization_infeasible.json) | Budget-constrained example where tested candidates are infeasible |
| [risk_summary.json](risk_summary.json) | Illustrative conditional summary shape; no samples retained |
| [benchmark_peers.json](benchmark_peers.json) | Ten compatible synthetic annual peers |
| [benchmark_result.json](benchmark_result.json) | Midpoint-ranked synthetic intensity comparison |

The optimization example deliberately contains only one feasible strategy; it demonstrates joins and status, not NSGA-II quality or a global optimum. Add a multi-point frontier fixture for chart and dominance tests at C0.

The risk summary is a shape fixture with illustrative numbers. Build a zero-uncertainty fixture and actual Monte Carlo outputs during WS3 implementation. Do not assert that this summary was generated by the supplied uncertainty model.

Baseline horizon totals are 1,200 tCO₂e, GBP 12,000,000 revenue and GBP 1,200,000 operating profit. The nonzero scenario follows [ACTION_MODEL.md](../docs/ACTION_MODEL.md). Schema version is `1.0.0`; IDs include a deterministic SHA-256 prefix for strategy identity based on the exact baseline/config/assumptions tuple.
